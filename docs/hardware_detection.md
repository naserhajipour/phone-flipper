# تشخیص سخت‌افزار

این سند توضیح می‌دهد برنامه چگونه سخت‌افزار گوشی را بررسی می‌کند و هر وضعیت چه معنایی دارد.

## وضعیت‌ها

- **داخلی (Native)** – گوشی خودش سخت‌افزار لازم را دارد.
- **نیازمند پل (Bridge)** – برای این کار به ماژول خارجی نیاز است.
- **ناموجود (Absent)** – سخت‌افزار در دستگاه نیست.

## دوازده بررسی

| بررسی | منبع واقعی |
|---|---|
| NFC | `NfcAdapter.getDefaultAdapter` و `FEATURE_NFC` |
| HCE | `FEATURE_NFC_HOST_CARD_EMULATION` |
| مادون قرمز | `ConsumerIrManager.hasIrEmitter()` و بازهٔ فرکانس حامل |
| بلوتوث | `BluetoothManager.getAdapter()` و `FEATURE_BLUETOOTH_LE` |
| رادیو زیرگیگاهرتز | همیشه «نیازمند پل»؛ اندروید API ارسال ندارد |
| میزبان USB | `FEATURE_USB_HOST` و سرویس `UsbManager` |
| دوربین | `FEATURE_CAMERA_ANY`، فلاش و فهرست `CameraManager` |
| میکروفون | `FEATURE_MICROPHONE` |
| شتاب‌سنج، ژیروسکوپ، مغناطیس‌سنج، نور، مجاورت، فشارسنج | `SensorManager.getDefaultSensor` |
| هستهٔ آفلاین | ثابت؛ مانیفست مجوز اینترنت ندارد |

## نکات

- همهٔ ویژگی‌ها در مانیفست `required="false"` هستند تا برنامه روی گوشی‌های بدون NFC یا IR هم نصب شود.
- جزئیات هر ردیف (نام سازندهٔ حسگر، توان مصرفی، تعداد دوربین، فرکانس‌های IR) واقعی و از خود سیستم است.
- گزارش کامل را می‌توان به‌صورت متن یا JSON از صفحهٔ گزارش به اشتراک گذاشت.

## ملاحظات قانونی

ارسال RF در باندهای تنظیم‌شده ممکن است در کشور شما محدود یا نیازمند مجوز باشد. ارسال تنها روی
تجهیزات خودتان و مطابق قانون محلی مجاز است.
