# English

Phone Flipper is a beginning framework for a realistic Android-based gateway to Flipper Zero-like actions.

# فارسی

Phone Flipper یک چارچوب اولیه برای یک دروازه اندرویدی واقع‌گرایانه برای انجام کارهایی شبیه فلیپر زیرو است.

## What the app does

- detects phone hardware
- checks NFC and HCE
- checks IR support
- checks BLE and USB host support
- warns that Sub-GHz RF needs external hardware

## این اپ چه کاری انجام می‌دهد

- تشخیص سخت‌افزار گوشی
- بررسی NFC و HCE
- بررسی پشتیبانی IR
- بررسی BLE و USB Host
- هشدار اینکه RF زیرگیگاه نیاز به سخت‌افزار جانبی دارد
