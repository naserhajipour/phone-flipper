# راهنمای اتصال ماژول خارجی

## قطعات پیشنهادی

- ESP32 DevKit
- CC1101 RF module
- سیم‌جو یا هدر
- منبع تغذیه 3.3V
- کابل USB یا BLE

## نوع اتصال

### 1) BLE

بهترین گزینه برای استفاده ساده با گوشی.

- ESP32 به‌عنوان سرور BLE
- گوشی به‌عنوان کلاینت BLE
- ارسال فرمان‌ها به صورت UART-over-BLE

### 2) USB-OTG

اگر گوشی از OTG پشتیبانی می‌کند، می‌توان ماژول را با کابل USB به گوشی وصل کرد.

- سریال USB
- ارسال و دریافت داده
- مناسب برای تست‌های دقیق‌تر

## سیم‌کشی پیشنهادی ESP32 + CC1101

- ESP32 SPI → CC1101 SPI
- GDO0/GDO2 → GPIO مناسب
- VCC → 3.3V
- GND → GND

## نکته امنیتی و قانونی

قبل از ارسال هرگونه سیگنال رادیویی، مطمئن شوید که این کار مجاز و قانونی است.
